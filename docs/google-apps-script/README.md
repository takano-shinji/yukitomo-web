# 在庫・注文スプレッドシートの設定

1. Googleスプレッドシートを新規作成する（名前は自由。例: 雪ともショップ在庫）。
2. シートを2枚作る。タブ名は次のとおりにする。
   - `在庫` … 1行目に見出し `variantId / 商品名 / フレーム / レンズ / 在庫数` を入力。2行目以降に商品を入力（variantId は `lib/shop/products.ts` の `variants[].id` と一致させる）。
   - `注文` … 1行目に見出し `日時 / 注文ID / variantId / 商品名 / フレーム / レンズ / 数量 / 小計 / メモ` を入力。
3. 拡張機能 → Apps Script を開き、`inventory.gs` の内容を貼り付けて保存する。
4. プロジェクトの設定（歯車）→ スクリプト プロパティ → `SECRET` に、推測されにくい長い文字列を設定する。
5. デプロイ → 新しいデプロイ → 種類「ウェブアプリ」。実行ユーザー「自分」、アクセスできるユーザー「全員」でデプロイし、発行された URL を控える。
6. `.env.local` に次を設定する。
   - `STOCK_SHEET_URL` … 手順5のURL
   - `STOCK_SHEET_SECRET` … 手順4と同じ値
